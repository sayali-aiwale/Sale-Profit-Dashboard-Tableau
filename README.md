# Sales Analytics Dashboard

## Overview
This project is an interactive Tableau dashboard developed to analyze sales and profit performance. The dashboard helps users identify trends, compare category-wise performance, and gain business insights through visualizations.

## Features
- Sales Analysis
- Profit Analysis
- Category-wise Performance
- Interactive Filters
- Data Visualization

## Tools & Technologies
- Tableau

## Dashboard Insights
- Analyzed sales and profit trends.
- Identified top-performing categories.
- Compared category-wise business performance.
- Generated business insights through visual reports.
